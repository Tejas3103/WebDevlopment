# 🌐 JavaScript Web Development Projects

A collection of various **JavaScript** projects and exercises, aimed at helping you improve your web development skills. From basic concepts to more advanced topics, these projects cover a wide range of real-world scenarios and challenges that will help you master **JavaScript**.

## 🚀 Projects Overview

- 🖥️ **Project 1:** Basic DOM Manipulation
- 🎨 **Project 2:** Interactive Web Forms
- 🕹️ **Project 3:** JavaScript Game Development
- 📊 **Project 4:** Data Visualization with JavaScript
- 🔒 **Project 5:** Basic Authentication System
- 💬 **Project 6:** Chat Application (Vanilla JS)

## 🛠️ Tech Stack

- **JavaScript** (ES6+)
- **HTML5** / **CSS3**
- **DOM Manipulation**
- **LocalStorage / SessionStorage**
- **AJAX / Fetch API**
- **WebSockets** (for chat app)
  

## 🚀 How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Tejas3103/WebDevlopment.git
   cd WebDevlopment/javascript
   ```

2. **Open the desired project folder:**
   - Each project has its own folder (e.g., `basic-dom-manipulation/`, `interactive-forms/`).
   - Navigate to the project you want to run.

3. **Open the HTML file in your browser:**
   - Open the `index.html` file or project-specific HTML file directly in a web browser (Chrome, Firefox, etc.).
   
> **Note**: Some projects may require a local server (e.g., the chat app may require WebSocket support), but most can run directly in your browser.
