## 🚀 How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Tejas3103/WebDevlopment.git
   cd WebDevlopment/javascript
   ```

2. **Open the desired project folder:**
   - Each project has its own folder (e.g., `basic-dom-manipulation/`, `interactive-forms/`).
   - Navigate to the project you want to run.

3. **Open the HTML file in your browser:**
   - Open the `index.html` file or project-specific HTML file directly in a web browser (Chrome, Firefox, etc.).
   
> **Note**: Some projects may require a local server (e.g., the chat app may require WebSocket support), but most can run directly in your browser.
